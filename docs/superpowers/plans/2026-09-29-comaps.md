# CoMaps (D-069) Implementation Plan

> **For agentic workers:** executed inline with superpowers:executing-plans,
> test first for every task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** carry CoMaps as a pinned `git` build and its maps as a D-049 data
unit chosen by the station's regions, with the position gap written down.

**Architecture:** five optional fields on `GitInstall` (`commit`,
`submodules`, `build_python`, `prepare`, `extra_files`) that the git backend
turns into engine-owned steps; a new `mwm-regions` install method shaped like
the Kiwix books backend on the reference branch (resolved before the plan
prints, HEAD-checked, fetch, verify, install, prune, remove); a
`maps comaps` verb that prepares the per-user state and execs the app.

**Spec:** `docs/superpowers/specs/2026-09-29-comaps-design.md`.

**Machine rules:** every command under `nice -n 19 ionice -c 3`; pytest with
`-p no:cacheprovider`; no GUI, no sudo, no real install, no CoMaps build; fake
`git`/`cmake` only; public example regions (Vermont, Delaware) and `N0CALL`.
